## 安装说明

### 日志哨兵 (fnlogpush)

飞牛NAS日志监控与多渠道推送工具

**下载地址**: [fnlogpush.fpk](fnlogpush/fnlogpush.fpk)

**功能**：
- 实时监控系统日志和备份进度
- 支持企业微信、钉钉、飞书、Bark、PushPlus、MeoW等推送渠道
- Web界面管理、事件订阅、免打扰和告警聚合
- **事件管理功能** - 添加/编辑/删除自定义事件
- **事件查询** - 可查询数据库中事件的最新记录
- **5分钟无操作自动退出登录**

**界面特性**：
- 6个精选主题（深色/深海蓝/清新绿/暮色橙/科技感霓虹）
- 加载动画、骨架屏、卡片悬浮动效
- 科技感霓虹主题（Cyber）
- 状态指示器脉冲发光
- 自定义滚动条、输入框增强效果

**更新日志 (v0.9.31)**：
- 暗夜紫主题修复：ThemeManager.setTheme现在始终添加theme-xxx class

**更新日志 (v0.9.5)**：
- 丰富推送信息：相册照片数量、相册名称、备份路径等
- 分享相册时只推送分享消息，不推送新建相册消息
- 点击备份卡片保存按钮时自动启动/停止备份监控
- 系统状态卡片优化：数据库和监控状态同行动态
- 删除系统状态卡片的重置监控按钮

### USB自动同步 (usbrsync)

USB存储设备自动同步工具，检测到USB设备插入后自动同步指定目录。

**下载地址**: [usbrsync.fpk](usbrsync/usbrsync.fpk) (USBRsyncCgi)

**功能**：
- 单向同步 - 从源目录同步到目标目录
- 双向同步 - 源目录和目标目录双向同步
- 插入自动同步 - 检测到USB设备插入时自动执行同步任务
- 手动同步 - 随时手动触发同步任务
- 实时显示同步进度

**界面特性**：
- 全新深色主题设计（渐变背景 + 毛玻璃效果）
- 响应式布局（自动适配桌面端和移动端）
- 流畅动画（卡片淡入、悬停变换）
- 实时日志刷新

### USB自动同步 (usbrsync1 · Node.js 版)

USB 插入自动同步（Node.js 单进程版），带 `--delete` 三重护栏、真实进度、同步历史与统计概览。
v0.5.1 修复大容量 exFAT/NTFS 盘（fuse 挂载）在源目录浏览时「无权限」的问题：按挂载 owner
降权读取，rsync 预检与同步进程同步降权；新增 `GET /api/diag_usb` 诊断接口。

**下载地址**: [usbrsync.fpk](usbrsync1/usbrsync.fpk) ｜ **完整版本历史**: [README](usbrsync1/README.md)

### 清理精灵 (fnclearup)

飞牛 NAS 的系统清理与重复文件扫描工具（Node.js 版）。扫描所有卷，找出已卸载应用的残留目录、
已失效的网盘挂载、无主的 Docker 卷、系统缓存与回收站垃圾，以及重复文件、相似图片、空目录与大文件。

**下载地址**: [fnclearup.fpk](fnclearup/fnclearup.fpk) ｜ **完整版本历史**: [README](fnclearup/README.md)

**清理能力**
- 应用残留 —— 与已安装应用列表对比，识别孤立 `@app*` 目录（含关联系统用户）
- 网盘 / Docker —— 已删除网盘的挂载残余、无主卷与镜像
- 系统清理 —— 缓存、日志、内核、tmp，带审计清单可回滚
- 回收站 —— 按卷扫描 `.@#local/trash`，可预览与批量清空

**扫描能力**
- 重复文件 —— 三级过滤（大小 → 头部哈希 → 全文件哈希），哈希线程池 + 断点续扫
- 相似图片 —— 内容感知比对，带左右对比弹窗
- 空目录 / 大文件 / 同名前缀 —— 独立面板，清单可导出

**安全与运维**
- 删除类操作全部走路径白名单与分区校验，危险路径默认拒删
- 定时任务（每日 / 每周 / 间隔）、执行历史与报表、系统通知
- 应用数据统一落在 `<PKGVAR>/data/`（跟着安装卷走），不再与安装目录混放

**界面特性**
- 设计系统令牌化，深色 / 浅色主题齐备，桌面与移动端自适应
- KPI 概览、扫描进度与耗时、可展开明细、内联操作反馈

**最近更新 (v0.15.1)**
- 修复应用数据目录写死 `/vol3`：改为「框架注入的 TRM_PKGVAR → 从安装路径反推 → 兜底」，
  手动启动不再与框架启动分家（以前会让界面开关与计划任务落在两个目录）

### 智能识别服务 (fnaiapi)

给 MT Photos 照片库用的本地 AI 引擎，人脸、以文搜图、文字识别三件事一次装好。

**下载地址**: [fnaiapi.fpk](fnaiapi/fnaiapi.fpk)

**三个能力**
- 人脸识别：自动整理人物相册，输出 512 维特征，和 MT Photos 现有格式一致
- 以文搜图：输入一句话找照片（CLIP 图文向量，512 维）
- 文字识别：截图、单据、路牌上的文字都能搜（PP-OCRv4 / v6 可切）

**性能（2 核 NAS 实测，与 mt-photos-ai 对比）**
- 人脸 1.6 秒 / 张（对方 43 秒）、以文搜图 0.7 秒（对方 9.4 秒）、文字识别 2.4 秒（对方 18.5 秒）
- 整轮内存峰值 1.5 GB（对方 2.5 GB）；空闲 5 分钟自动卸载模型，平时几乎不占内存

**上手要点**
- 模型不随应用打包，装好后在「设置」里一键准备（可复用本机 MT Photos AI 容器的权重，也可直接下载）
- MT Photos 里【系统配置 → 人脸识别 → API配置】和【系统配置 → 智能识别】都指向 `http://你的NAS:46092`，Key 在「接入」页一键复制
- 切换过来无需清空已有识别结果；识别历史存在本地，重启不丢
- 核显可用时自动加速，无核显回退纯 CPU，功能不受影响
